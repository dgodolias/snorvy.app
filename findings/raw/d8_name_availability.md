## Per-name details

### Snorvey

- iOS: nothing surfaces.
- snorvey.app / snorvey.com: both NXDOMAIN (free).
- Trademark: no hits on Justia/USPTO web search.
- Recommendation: 🟢 SAFE — cleanest name across all 4 axes.

### Snorta
- Play: 10 results, none named Snorta. SnoreLab appears as adjacent.
- iOS: only Mattel "Snorta!" board game; no app collision.
- snorta.app: free. snorta.com: parked at aftermarket.com (likely buyable, not active).
- Trademark: no Snorta mark; SNORA / SNORRX / SNORETESTER cover hardware/medical, low overlap with software class 9.
- Recommendation: 🟢 SAFE — slight risk of board-game brand confusion.

## Top 3 ranked recommendations

1. **Snorvey** — Cleanest across the board: zero Play/iOS collisions, both .app and .com NXDOMAIN (registerable today for ~$12-20/yr), no trademark on USPTO/Justia. Phonetic blend of "snore" + "survey" telegraphs the recording/analysis function.
2. **Snorta** — Strong runner-up: zero app collisions, .app free, .com only parked (purchasable from aftermarket); clear "snore" phonetics. Minor risk of confusion with the Mattel board game (different category, low SEO overlap).
3. **Bedtape** — Only name with BOTH .app and .com fully free + zero collisions, but awkward branding ("tape" implies cassette nostalgia which fits "record your sleep" but reads weird). Use as fallback only if you want maximum domain control.
